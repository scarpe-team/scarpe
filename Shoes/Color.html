Overview

A colour, as rgb, gray, the named colours and ask_color give it: four Integers from 0 to 255 (manual 643-655, 790-834, ledger D1). It is still an Array, so code that destructures, compares or sends colours keeps working, and displays read it as before.

def self.from(value)
  case value
  when nil then nil
  when Array then Shoes.rgb(*value)
  else Shoes::Colors.to_rgb(value)
  end
end
