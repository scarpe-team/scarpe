#initialize(*args, **kwargs) ⇒ Para

Initializes a new instance of the Para drawable. There are different methods to instantiate slightly different styles of Para, such as tagline, caption and subtitle. These will always be different sizes, but may be generally styled differently for some display services.

Examples:

Shoes.app do
  p = para "Hello, This is at the top!", stroke: red, size: :title, font: "Arial"

  banner("Welcome to Shoes!")
  title("Shoes Examples")
  subtitle("Explore the Features")
  tagline("Step into a World of Shoes")
  caption("A GUI Framework for Ruby")
  inscription("Designed for Easy Development")

  p.replace "On top we'll switch to ", strong("bold"), "!"
end

    The text content of the paragraph.

def initialize(*args, **kwargs)

  if kwargs[:font]
    arr= parse_font(kwargs[:font])
    
    if arr[0] != nil

      kwargs[:emphasis] = arr[0]

    end

    if arr[1] != nil

      kwargs[:font_variant] = arr[1]

    end

    if arr[2] != nil

      kwargs[:font_weight] = arr[2]

    end

    if arr[3] != nil

      kwargs[:size] = arr[3]

    end

    if arr[4] != ""

      kwargs[:family] = arr[4]

    end

  end
 
  # Don't pass text_children args to Drawable#initialize
  super(*[], **kwargs)
    
  # Text_children alternates strings and TextDrawables, so we can't just pass
  # it as a Shoes style. It won't serialize.
  update_text_children(args)

  create_display_drawable
end

#cursor=(val) ⇒ Object

Set the text cursor position. Accepts integer (character position), :marker, or nil (remove the cursor and the marker). :marker is Shoes 3.1's "drop the selection": with a marker set, the caret goes to the start of the selection and the marker is cleared; with none, nothing changes (s3t_textblock.c:602-616, ledger F14). Editors call it after every edit. String/symbol values set the CSS cursor style directly (via Shoes style prop_change).

def cursor=(val)
  case val
  when Integer
    self.text_cursor = val
  when :marker
    if @text_marker
      self.text_cursor = [@text_cursor, @text_marker].compact.min
      self.text_marker = nil
    end
  when nil
    self.text_cursor = nil
    self.text_marker = nil
  else
    # For CSS cursor types (:text, :arrow, etc.), set the cursor style directly
    # We can't call super because method_missing would redefine cursor= on Para
    @cursor = val.to_s
    send_shoes_event({ "cursor" => @cursor }, event_name: "prop_change", target: linkable_id)
  end
end

def highlight
  c = @text_cursor || 0
  m = @text_marker
  return [c, 0] if m.nil?
  start = [c, m].min
  len = (c - m).abs
  [start, len]
end
