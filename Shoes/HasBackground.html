#background(color, options = {}) ⇒ Shoes::Background

Create a Background drawable with the given color. Returns the Background drawable so it can be styled: @back = background blue @back.style :height => 10

In Shoes3, background() inside a slot creates a separate drawable that can be independently styled, shown/hidden, and destroyed.

Parameters:

  • color (String, Range, Array) —

    the fill color (string, gradient Range, or RGBA array)

  • options (Hash) (defaults to: {}) —

    optional styles like :curve, :height, :width

Returns:

def background(color, options = {})
  # Create the Background drawable with the fill color, in this slot or where a
  # widget sends its DSL calls. We need to set up the app context properly so the
  # drawable can access @app during initialization.
  instance = nil
  @app.with_slot(dsl_target) do
    Shoes::Drawable.with_current_app(self.app) do
      instance = Shoes::Background.new(fill: color, **options)
    end
  end
  instance
end
