# Entries with no case

Every other `element.*`, `common.*` and `elements.*` entry in `native/research/manual_inventory.json` has at least one case in this directory.

- `element.video` (manual 2131-2133): ledger L4 rules VLC-backed video out of scope, so the core suite asserts nothing about it.
- `elements.other_types` (manual 2546-2548): the claim is that seven element types look and act the same on every OS, which one machine cannot observe. Each type has its own entries and cases.
