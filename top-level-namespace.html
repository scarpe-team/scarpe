SHOES_REQUIRE_CASE_MAP =

Shoes3 compatibility: case-insensitive require fallback. Shoes3 ran on JRuby/Windows where require was case-insensitive, so many legacy scripts have wrong-case requires like: require 'CSV' (should be 'csv') require 'FileUtils' (should be 'fileutils')

This shim catches LoadError and retries with the downcased name.

{
  "CSV" => "csv",
  "FileUtils" => "fileutils",
  "YAML" => "yaml",
  "JSON" => "json",
  "Net/HTTP" => "net/http",
  "URI" => "uri",
  "Digest" => "digest",
  "Base64" => "base64",
  "StringIO" => "stringio",
  "Tempfile" => "tempfile",
}.freeze
