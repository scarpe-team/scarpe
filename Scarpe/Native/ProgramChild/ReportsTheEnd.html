Overview

An error that escapes the event loop ends the program ("exit"): the renderer died under it, say (ChildDied). The parent has heard it, so it ends with status 1 and is not printed.

def run
  super
rescue SystemExit, SignalException, NoMemoryError
  raise
rescue Exception => e
  Shoes.report_error(e, during: "exit")
  exit 1
end
