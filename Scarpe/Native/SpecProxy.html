Overview

Stands in for a Lacci drawable inside test code. Anything the drawable answers is forwarded, so proxy.text, proxy.checked? and proxy.replace(...) are plain Lacci.

def trigger_click(*args)
  return trigger("click", *args) unless args.empty? && !@obj.is_a?(Shoes::SubscriptionItem)

  automation.click({ id: @linkable_id })
end
