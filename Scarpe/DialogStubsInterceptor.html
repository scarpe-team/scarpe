Module: Scarpe::DialogStubsInterceptor

Defined in:
lib/scarpe/shoes_spec.rb

Overview

Module to prepend to Shoes::Builtins for dialog interception. When a dialog is stubbed, returns the stubbed value immediately instead of dispatching to the display service.
